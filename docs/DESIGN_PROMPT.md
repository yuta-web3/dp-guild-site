## プロンプト本文

> 添付画像は当社（株式会社DP-GUILD）のロゴです。使用許諾済みなので、そのまま使って構いません。ロゴは透過PNGです。背景色はロゴから決めず、作品として最適な地を選んでください。
>
> このサイトは、当社の技術力そのものを見せる作品です。ロゴのアイソメトリックな不可能図形——「あり得ない構造が成立して見える」という性質を、サイト全体の設計思想として展開してください。整った company site ではなく、開いた瞬間に「この会社は作れる」と分かるものを作ってください。
>
> 構図は非対称に。グリッドを意図的に破り、要素を画面外へはみ出させ、余白の量を不均等にしてください。中央揃えを避けてください。セクションの境界を斜めに切る、要素を重ねる、意図的にずらす。整列していないことが設計であると分かる不揃いさにしてください。ただし読む順序だけは崩さないでください。
>
> **【実装の構成】**
> - Next.js 15 App Router（app/page.tsx）、TypeScript、React 19
> - Tailwind CSS v4（app/globals.css に `@import "tailwindcss"`。設定ファイルは使わずCSS内で定義）
> - Framer Motion（useScroll / useTransform / useSpring / useMotionValueEvent を使う）
> - lucide-react
> - 既存の components/Header.tsx と components/ContactForm.tsx の作法に合わせる（'use client' を先頭、@/components/... でimport）
> - 色はハードコードのhex（例 text-[#0F172A]）
>
> **【ページ構成】** 次の5ブロック。順序は守ってください。
> 1. ファーストビュー — 会社名と、事業領域6つ（サイト／SNS・動画／EC／アプリ・システム／集客／DX）をアイコンで一目で示す。会社説明の文章は書かない。右側に問い合わせフォーム。
> 2. 実績 — カテゴリ絞り込みボタン（すべて／Web／SNS・動画／EC／アプリ・システム／コンサル）と、「困っていたこと → どう解いたか → お客様の声」の3点構成のカードを3枚。
> 3. サービス — 集客したい／採用したい／つくってほしい／社内を楽にしたい、の4つの入口カード。価格は載せない。
> 4. 代表 — 写真と名前、メッセージ。
> 5. 会社情報 — 社名・所在地・設立・代表者・法人番号と、法務3ページへのリンク。
>
> 問い合わせは常時目に入るように。ヘッダーのボタン、ファーストビューのフォーム、実績とサービスの間の帯、画面右端の追従ボタンの4箇所。電話番号は載せないでください。
>
> **【アニメーション — ここが主役です】**
> スクロールを演出の駆動軸にしてください。useScrollでスクロール量を取り、useTransformで複数の要素を別々の速度・別々の方向に動かしてください。スクロールが進むほど何かが組み上がる、あるいは解体される、という時間軸を作ってください。
>
> ファーストビュー — ロゴの立方体をSVGで再構築し、線が1本ずつ引かれて面が生成される描画アニメーションから始めてください（stroke-dasharray と stroke-dashoffset）。組み上がったあと、スクロールに応じて立方体が分解して各面が別方向へ飛んでいく。背景のアイソメトリック格子は常時ゆっくり流れ続けます。
>
> セクション遷移 — 単純なフェードインは使わないでください。要素ごとに遅延をずらし（stagger）、それぞれ違う方向・違う距離から入る。あるものは下から、あるものは横から、あるものは回転しながら。useSpringで減衰を与え、機械的でない動きにしてください。
>
> 文字 — 見出しは1文字ずつ、あるいは単語ごとに時間差で現れる。マスクを使って下から押し出す形か、グラデーションが左から走査して文字を照らす形。
>
> カード — スクロールで視界に入るとき、カードがわずかに傾いた状態から水平に戻る。ホバーで枠線のグラデーションが回転する（conic-gradient ＋ @property で角度をアニメーション）。
>
> 背景 — セクションごとに、アイソメトリックの線が生成・消滅を繰り返すレイヤーを敷いてください。Canvasで描画して構いません。スクロール速度に応じて線の密度が変わると尚良いです。
>
> 数値・カウンタ — 実績の数字があるなら、視界に入ったときにカウントアップ。
>
> **【禁止事項はこれだけです】**
> - 文字が読めなくなる状態を作らない。動いている背景の上に本文を置く場合、backdrop-filter か半透明の板を敷いてコントラストを確保する
> - 文字自体を常時動かし続けない。出現時のアニメーションは可、その後は静止
> - prefers-reduced-motion: reduce で全て無効化する。これは必須
> - スクロールを乗っ取らない（スムーススクロールライブラリによる慣性の追加はしない）
>
> **【性能について】**
> 演出を優先して構いませんが、transform と opacity を主体にし、Canvasを使う場合は requestAnimationFrame で描画してください。60fpsを目標にしつつ、表現のために多少重くなることは許容します。

## 使うときの補足

このプロンプトを渡したうえで、**別途決まっている方針を必ず併せて伝えること。**
プロンプト単体だと、以下と食い違う結果になる。

| 併せて伝えること | 理由 |
|---|---|
| **飾りの英語ラベルを使わない**（PRICE / VIEW / CONTACT 等） | パッと見て意味が入らない。日本語にする |
| **CTAは同時に見えるのが1つになるように** | 4箇所同時は鬱陶しい。回遊するトップは複数可だが、重ねて見せない |
| **人はファーストビューしか見ない** | FVの中で問い合わせか資料請求まで到達できる形にする |
| **価格をカウントアップさせない** | 途中で止まると誤った金額が出る |

サービスページ側の仕様は `docs/SERVICE_PAGES.md` を参照。
