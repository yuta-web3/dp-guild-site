# P2　施策を売る会社ではありません

制作会社に相談すると、たいてい制作を勧められます。広告代理店に相談すると広告を勧められます。売るものが決まっているからです。

DP-GUILDが最初にやるのは、**何から手をつけるかを決めること**です。その結果として「今は作らない」「うちには頼まない」という結論になることもあります。

創業は2019年、滋賀県甲賀市。地域の中小企業に向き合う中で、施策より先に判断が要ると気づきました。

# P4〜P9　実際にどう判断したか

**各ページの型（6件とも同じ）**

```
相談されたこと
　↓
選択肢（A / B / C）
　↓
却下した案と、その理由   ← ここが読ませどころ
　↓
決めたこと
　↓
そう決めた理由
　↓
どうなったか
```

## 01　醸造業（製造業）

- **相談**：在庫管理が非効率で、顧客満足度も上げたいが、予算が限られている
- **選択肢**：A 高機能な在庫管理システム（月額5万円〜）／B シンプルな在庫管理＋Wi-Fi環境整備／C SNSマーケティングに全振り
- **却下**：A。機能の8割は使わない見込み。運用負荷が増えるリスク
- **決めたこと**：Bを基盤に、余った予算でCを小規模実施
- **理由**：まず業務効率化で時間を確保し、その上でマーケティングに取り組む順序が現実的
- **どうなったか**：在庫ロス減少、リピーター増加。浮いた時間でSNS運用が継続できている
  - > **数字が要る**（在庫ロスが何%減ったか、棚卸しの時間が何時間減ったか）

## 02　ストレッチスタジオ（サービス業）

- **相談**：新規開業。予算が限られている中で集客と信頼性を両立したい
- **選択肢**：A フル機能のコーポレートサイト＋予約システム／B 必要最低限のサイト＋外部予約サービス連携／C SNSのみで集客
- **却下**：A。開業直後は予約数も読めない。過剰投資のリスク
- **決めたこと**：B。サイトはシンプルに、予約は実績ある外部サービスを活用
- **理由**：信頼性は「サイトがあること」で担保できる。機能は軌道に乗ってから追加すればいい
- **どうなったか**：集客力向上、リピーター獲得。予算内で安定経営の基盤ができた
  - > **数字が要る**（予約数、月の新規客数）

## 03　忍者服工房（製造業）

- **相談**：伝統的な忍者服をECで販売したいが、どこまで作り込むべきか迷っている
- **選択肢**：A Shopify等の既存プラットフォーム／B フルスクラッチでオリジナルEC／C BASE等の無料サービスで様子見
- **却下**：A。テンプレートでは商品の世界観を表現しきれない
- **決めたこと**：B。商品の魅力を最大限伝えるシンプル設計でフルスクラッチ
- **理由**：「忍者服」という唯一無二の商品には、唯一無二の見せ方が必要
- **どうなったか**：訪問者数・売上の増加。商品の世界観が伝わり、ファンが定着
  - > **数字が要る**（訪問者数、売上の伸び）

## 04　脳疾患特化リハビリ（医療）

- **相談**：脳疾患特化型リハビリの認知が低い。Web集客を強化したいが何から手をつけるべきか
- **選択肢**：A 広告に予算を集中投下／B LP構築＋SEO対策／C SNSでの認知拡大
- **却下**：A。認知がない状態で広告を打っても、受け皿（LP）がなければ無駄になる
- **決めたこと**：B。まずLPで信頼感を醸成し、SEOで検索経由の流入を確保
- **理由**：「脳疾患 リハビリ」で検索する人は本気度が高い。その人に刺さるLPが先
- **どうなったか**：Web問い合わせ大幅増加、コンバージョン率向上。広告は次のフェーズで検討中
  - > **数字が要る**（問い合わせ件数、CVR）

## 05　デザインスクール（教育）

- **相談**：Instagram活用で認知を広げたいが、どんなコンテンツが効果的かわからない
- **選択肢**：A 受講生の作品紹介を中心に投稿／B 教育コンテンツの動画化でバイラルを狙う／C 広告中心で認知拡大
- **却下**：A。フォロワー外へのリーチが限定的。認知拡大には弱い
- **決めたこと**：B。学びになる動画コンテンツで自然な拡散を狙う
- **理由**：「教えてくれる」コンテンツはシェアされやすい。広告費なしで認知を取れる可能性
- **どうなったか**：**動画1,600万回再生**。受講生獲得が大幅増加
  - > 6件で唯一、数字が入っている。**この件を先頭に置くことを検討**

## 06　大手食品メーカー（製造業）

- **相談**：データドリブンマーケティングを始めたいが、どのベンダーを選べばいいかわからない
- **選択肢**：A 知名度の高い大手ベンダーに依頼／B 要件を明確にしてから複数ベンダーを比較選定／C 社内で内製化
- **却下**：A。要件が曖昧なまま発注すると、後から「こうじゃなかった」が発生
- **決めたこと**：B。まず要求定義を策定し、RFP作成後に複数社を比較
- **理由**：「何がしたいか」を言語化してから選ばないと、ベンダーの提案が正しいか判断できない
- **どうなったか**：最適なベンダー選定成功。要件に合ったシステム導入でマーケティング精度向上
  - > **この件は自社で受注していない**（他ベンダーに流している）。それが逆に「売らない会社」の証明になる。その旨を明記する案
